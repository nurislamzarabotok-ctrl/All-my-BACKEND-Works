## 1. Трейсбэк

В исходном коде `DELETE /messages/99` вызывал ошибку, потому что `get()` возвращал `None`, а потом `delete()` пытался удалить `None` из списка.

Последняя ошибка по логике исходного кода:

```text
ValueError: list.remove(x): x not in list
```

Последняя строка значит: Python не нашел `None` в списке сообщений, поэтому удалить его не смог.

Файл, который надо было проверить первым: `storage.py`, метод `delete()`, строка с `self.messages.remove(self.get(message_id))`. Причина начинается в `get()`: если сообщения нет, там возвращался `None`.

Статус код: 500.

Примечание: это описание ошибки исходного кода. Полный traceback из терминала надо вставить после запуска исходной версии, если преподаватель требует именно скопированный вывод.

## 2. Баг

Запрос: `02 Create second message`.

Второе сообщение получало ID `1`, хотя должно было получить `2`.

Причина была в строке:

```python
self.next_id = len(self.messages)
```

После первого сообщения длина списка была `1`, и следующий ID опять оставался `1`. Я заменил строку на:

```python
self.next_id += 1
```

При проверке логики:
- `p self.messages` — `[]`, если список сообщений пустой.
- `p self.get(99)` в исходном коде — `None`, потому что такого сообщения нет.
