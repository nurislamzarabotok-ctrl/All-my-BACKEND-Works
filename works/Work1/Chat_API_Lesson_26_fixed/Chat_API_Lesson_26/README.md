## Run it

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
fastapi dev main.py
```

Windows PowerShell:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
fastapi dev main.py
```

Сервер: http://127.0.0.1:8000, документация: http://127.0.0.1:8000/docs.

## The API

| Request | Success | Errors |
|---|---|---|
| `GET /messages` | 200, the list | |
| `POST /messages` | 201, the new message | 422, 409 when the chat is full |
| `GET /messages/{message_id}` | 200, the message | 404 |
| `PATCH /messages/{message_id}` | 200, the message | 404, 422 |
| `DELETE /messages/{message_id}` | 204, no body | 404 |

Правила:
- Длина `author` от 2 до 32 символов. Длина `text` от 1 до 500 символов.
- `text` только из пробелов не принимается. Пробелы с концов текста удаляются.
- PATCH принимает только `text` и `pinned`. Оба могут быть пропущены но не могут быть `null`. Все остальные поля/ключи выдают ошибку 422.
- В чате может быть максимум 3 сообщения (`MAX_MESSAGES` в `storage.py`).
- Каждая ошибка 404 и 409 имеют одинаковое тело. Пример: `{"detail": "Message 99 not found", "code": "message_not_found"}`. Другие ключи не нужны.

## Если закончите раньше времени
`PATCH {"text": "   "}` может все еще отвечать со статус кодом 200 и сохранить значение в 3 пробела. Исправьте на 422, и сохраняйте только обрезанные строки без пробелов. Следите за порядком выполнения валидаторов: что выдает `None.strip()`?

## Исправление ошибок
| What you see | What it means |
|---|---|
| Bruno: `connect ECONNREFUSED 127.0.0.1:8000` | Не запущен сервер или запущен на другом порте |
| Запрос 01 фейлиться на новом запуске | Сервер не был перезапущен и хранит в себе старые сообщения |
| Bruno запускается но не отвечает | Сервер остановился с `(Pdb)`. Проверьте терминал и напечатайте `c`. |
| `ImportError: cannot import name 'ChatFull' from 'errors'` | Импортируете класс которого нет |
| 404 для существующего сообщения | `raise` внутри `for` цикла должен быть после него. |
| Четвертое сообщение было сохранено | `>` вместо `>=`. |
| `{"text": null}` все еще выдает 200 | Валидатор не работает с полем `"text"`, или `@classmethod` выше чем `@field_validator`. |
